# Формальна граматика SIPL

Машинозчитувана граматика: [`src/sipl/grammar/sipl.lark`](../src/sipl/grammar/sipl.lark) (Lark, парсер Earley).
Вона лежить у пакеті, щоб встановлений `sipl` мав її поруч; цей каталог описує відповідність курсу.

## Відповідність БНФ практикуму (с. 8–9)

| БНФ курсу | Правило Lark | Вузол AST |
|---|---|---|
| NP1 `<програма> ::= begin <оператор> end` | `start` | `Program` |
| NS1 `<змінна> := <вираз>` | `assign` | `Assign` |
| NS2 `<оператор> ; <оператор>` | `seq` (праворуч) | `Seq` |
| NS3 `if <умова> then <оператор> else <оператор>` | `if_` | `If` |
| NS4 `while <умова> do <оператор>` | `while_` | `While` |
| NS5 `begin <оператор> end` | `block` | `Block` |
| NS6 `skip` | `skip` | `Skip` |
| NA1–NA2 `<число>`, `<змінна>` | `num`, `var` | `Num`, `Var` |
| NA3–NA5 `+`, `–`, `*` | `add`, `sub`, `mul` | `BinOp` |
| NA6 `(<вираз>)` | `apar` | `ParenA` |
| NB1–NB2 `=`, `>` | `eq`, `gr` | `Cmp` |
| NB3 `∨` | `or_` | `Or` |
| NB4 `¬` | `not_` | `Not` |
| NB5 `(<умова>)` | `bpar` | `ParenB` |

## Неоднозначність і пріоритети

БНФ курсу неоднозначна (`<вираз> – <вираз>`, `<оператор> ; <оператор>`). Граматика
усуває це за пріоритетами з лекції 1-2 (від сильнішого до слабшого):

`*` → `+ –` → `= >` → `¬` → `∨` → `:=` → `while` → `if` → `;`

* `+ – *` лівоасоціативні: `1 - 2 - 3 = (1 - 2) - 3`.
* `;` розбирається праворуч: `S1; S2; S3 = S1; (S2; S3)`. Композиція `•` асоціативна (лема 1.1),
  тож на семантику це не впливає.
* Тіло `while`/гілки `if` — один оператор; кілька операторів беруться в `begin … end`.

## Лексика

* Змінні: `[A-Za-z_][A-Za-z0-9_]*`, крім ключових слів.
* Числа: `-?[0-9]+` (від'ємні літерали, як `–1` у БНФ).
* Ключові слова: `begin end if then else while do skip`.
* `∨` можна писати як `or`, `¬` — як `not` (зручно з клавіатури).
* Коментарі: `// до кінця рядка` (розширення для зручності, у БНФ курсу їх немає).
