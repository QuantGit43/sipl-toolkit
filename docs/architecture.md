# Архітектура

```
текст .sipl ──parser──▶ AST (SourceSpan) ──┬──▶ interpreter ──▶ кінцевий стан / trace (події)
                                           ├──▶ semantics   ──▶ семантичний терм, ланцюжок, правила
                                           └──▶ visualization ─▶ дерево виводу (text/JSON/DOT/SVG)
                         cli.py: обгортка над усіма шарами, JSON-конверт для інтеграцій
```

| Модуль | Відповідальність | Завдання |
|---|---|---|
| `src/sipl/grammar/sipl.lark` | формальна граматика | CORE-01 |
| `parser.py` | текст → власні вузли AST, діагностика з рядком/колонкою | CORE-02 |
| `ast.py` | типізовані вузли + `SourceSpan` | CORE-02 |
| `interpreter/` | стан `Var → Int`, виконання, ліміт кроків, події trace | CORE-03, CORE-04 |
| `semantics/` | `sem_P/S/A/B`, терми `AS^x, •, IF, WH, Sⁿ, x⇒, n̄, id`, друк text/LaTeX/JSON | SEM-01 |
| `visualization/` | дерево виводу за БНФ курсу, нумерація листків, експорти | VIS-01 |
| `cli.py` | команди `parse/check/run/trace/term/tree`, `--json` | CORE-05 |
| `vscode-sipl/` | підсвітка синтаксису (окремий клієнт) | IDE-01 |

Принцип з умови проєкту: мова «живе» у бібліотеці. Інтерпретатор, семантика й візуалізація
працюють з одним AST і не мають власних парсерів; VS Code-розширення не містить логіки мови.

## Ключові рішення

* **Lark + Earley.** Граматика читається як БНФ, а `(` у `(X + 1) > 2` і `(X > 1)`
  розрізняється без хаків. Програми навчальні й короткі, тож швидкість Earley не проблема.
* **Власне AST замість дерева Lark.** Трансформер перетворює дерево бібліотеки на dataclass-вузли.
  Дужки й `begin…end` зберігаються вузлами `ParenA/ParenB/Block`: на семантику вони не впливають
  (правила `NS_A_Par`, `NS_B_Par`, `NS_Stm_BE`), але потрібні, щоб дерево виводу відтворювало текст.
* **Невизначеність.** `x⇒(st)` для відсутньої змінної — помилка `R001`; цикл, що не завершується
  за `--max-steps`, — результат `↑` (код 4), а не зависання.
* **Терм будується з AST рекурсивно**, тим самим обходом, що й правила `NS_*` у практикумі.
  Той самий обхід з обмеженням глибини дає ланцюжок перетворень, як у лекції.
