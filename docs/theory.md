# Теоретична основа (для захисту)

## Синтаксис (практична 1, CORE-01/02, VIS-01)

Мова задається БНФ; програма коректна, якщо її можна вивести з `<програма>`.
`sipl tree` будує дерево виводу з AST: кожен внутрішній вузол — нетермінал з правилом
(NP1, NS1–NS6, NA1–NA6, NB1–NB5), листки — термінали. Обхід листків зліва направо
має дати текст програми — це і є перевірка синтаксичної коректності з практикуму
(`yield_matches_source`).

## Семантика (практична 2, SEM-01, CORE-03)

Програма — функція `State → State`, де `State = Var → Int` (часткове відображення).
Семантичний терм будується рекурсивно (`sem_P`, `sem_S`, `sem_A`, `sem_B`):

| Синтаксис | Правило | Терм |
|---|---|---|
| `begin S end` (програма) | NS_Prog | `sem_S(S)` |
| `x := a` | NS_Stm_As | `AS^x(sem_A(a))` |
| `S1; S2` | NS_Stm_Seq | `sem_S(S1) • sem_S(S2)` |
| `if b then S1 else S2` | NS_Stm_If | `IF(sem_B(b), sem_S(S1), sem_S(S2))` |
| `while b do S` | NS_Stm_Wh | `WH(sem_B(b), sem_S(S))` |
| `skip` | NS_Stm_skip | `id` |
| `n`, `x` | NS_A_Num, NS_A_Var | `n̄`, `x⇒` |
| `a1 + a2` (−, *) | NS_A_Add (Sub, Mult) | `S²(add, …)` (`sub`, `mult`) |
| `a1 = a2`, `a1 > a2` | NS_B_eq, NS_B_gr | `S²(eq, …)`, `S²(gr, …)` |
| `b1 ∨ b2`, `¬b` | NS_B_or, NS_B_neg | `S²(or, …)`, `S¹(neg, …)` |

Інтерпретатор реалізує формули обчислення композицій AF_AS, AF_SEQ, AF_IF, AF_WH:
`AS^x(fa)(st) = st ∇ [x ↦ fa(st)]`, `(f • g)(st) = g(f(st))`, `WH(fb, fs)(st) = stₙ`,
де `fb` істинна на `st₀ … stₙ₋₁` і хибна на `stₙ`.

## Властивості (лекція 3-4)

* Лема 1.1: `•` асоціативна → групування `;` не впливає на терм (тест `test_seq_grouping_does_not_matter`).
* Теорема 1.2: програми SIPL монотонні щодо розширення стану (тест `test_state_extension_is_monotone`).

## Межі автоматизації

* Нескінченність циклу в загальному випадку нерозв'язна (проблема зупинки), тому
  інтерпретатор лише обмежує кількість кроків і повідомляє, що результат вважається невизначеним.
* Доведення коректності (практична 3) інструмент не автоматизує; `sipl trace` допомагає
  перевірити інваріант на конкретних даних.
